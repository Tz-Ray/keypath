# The six KeyPath puzzles

Play them on the [KeyPath page](https://tz-ray.github.io/keypath/#challenges). Each folder holds the
puzzle's `ciphertext.txt` and, as **spoilers**, the author's `key.json`, the
`plaintext.txt` and `solve-path.md`, the intended way to crack it.

| # | level | title | files |
|---|-------|-------|-------|
| 1 | Warm-up | Type it like a local | [`challenge-01/`](challenge-01/) |
| 2 | Warm-up | Dos teclados, un mensaje | [`challenge-02/`](challenge-02/) |
| 3 | Easy | The Key Right of the Space Bar | [`challenge-03/`](challenge-03/) |
| 4 | Medium | Mother Tongue | [`challenge-04/`](challenge-04/) |
| 5 | Hard | A Friend from Afar | [`challenge-05/`](challenge-05/) |
| 6 | Expert | Each in Its Own Way | [`challenge-06/`](challenge-06/) |
